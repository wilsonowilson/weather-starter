# weather

The Zero to Hired Sprint 4 starter: a SvelteKit project that shows the weather from the free
[Open-Meteo](https://open-meteo.com) API. No account or key is needed.

## Start

```
npm install
npm run dev
```

Then open `localhost:5173` in Chrome.

## What is inside

| File | What it does |
|---|---|
| `src/lib/weather.js` | Your functions from Lesson 4.8: `getTemperature`, `toHours` and `getHours` |
| `src/routes/+page.svelte` | The home page |
| `src/routes/rain-today/+page.svelte` | The rain page, with three gaps for Lesson 4.10 |

## Put it live

Push to your own GitHub repository, then add it as a new project on Netlify. The Netlify adapter is
already set up in `vite.config.js`, so no settings are needed.
